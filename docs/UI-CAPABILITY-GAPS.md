## Implemented in this lane

- Native Research, Library, Places and Saved destinations, with model/import/storage controls in secondary Settings or disclosure.
- Private SQLite history of completed research and opened sources, persistent bookmarks and notes, searchable titles/questions/notes, deletion confirmation and explicit storage bounds.
- Full-screen saved source/result reading, persisted 18/22/26sp sizing, navy and cream reader themes, dates and original provenance, with no inference or rights promotion.
- Comparison of two actual saved records or two actual retrieved source passages; this presents evidence without generating a comparative answer.
- Portable UTF-8 Markdown snapshot/notebook export through the Android document picker, and read-granted content-URI sharing through the system chooser.

These statements describe implemented code. Runtime evidence and exact candidate identities are recorded separately; documentation itself is not execution proof.

## Editorial redesign follow-up

The redesign adds a light editorial shell, original icon destinations, actual bundled source browsing, live Saved filtering, disclosed record actions and durable per-record reader position. The latter supersedes the earlier Activity-only reading-position limitation. It does not close the remaining capability matrix: folders/tags, verified notebook reimport, personal document import (canonical330 is separate), OCR/voice, maps/GPS/routing, current hours/diet, semantic retrieval or larger-model hardware qualification remain outside this candidate. No competitive win is claimed. API37 loader verification is separate from physical ARM64/GrapheneOS and full-corpus capacity acceptance.
