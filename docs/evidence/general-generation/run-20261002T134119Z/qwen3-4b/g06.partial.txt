A temporary compiler used to build a better compiler is referred to as a bootstrap compiler in the context of compiler development. This type of compiler is often employed to create a more permanent or optimized compiler for a language, as indicated in [[S1]]. In contrast, a compiler targeting another operating system is a cross-compiler, which produces code for a different central processing unit (CPU) or operating system than the one on which the cross-compiler itself runs, as described in [[S1]]. The key difference lies in their purpose: a bootstrap compiler is a temporary tool for building a more robust compiler, while a cross-compiler is designed to generate code for a different target system.
