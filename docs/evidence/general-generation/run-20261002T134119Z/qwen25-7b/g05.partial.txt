Cross-compilation is a process where a compiler running on one type of computer or operating system generates code for a different type of computer or operating system. Assembly instructions are closely tied to an architecture because assembly language has a strong correspondence with the machine code instructions of a specific architecture, meaning that each assembly instruction typically maps to one machine code instruction. [[S2]]

The passage states that assembly language often has one statement per machine code instruction (1:1), but it also mentions that constants, comments, assembler directives, symbolic labels, and macros are generally supported, which means that assembly is not always exactly one statement per instruction.
