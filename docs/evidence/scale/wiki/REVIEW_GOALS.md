# Independent review scope

Review the sealed English encyclopedia staging artifact, its actual source and reader contracts, implementation, frozen probes and raw check results. Do not read planning history, `FINDINGS.md`, `LOOP_STATE.json`, supervisor state, private conversations or holdout data. Builder completion is not acceptance. Any persisted critic conclusion must be English, one sentence, at most 35 words.

The objective is an actual offline-readable pack derived from all fifteen pinned FineWiki English Parquet shards, with source revision/date/URL, attribution notices, math and units inspectable through bounded compressed blocks and a disk-backed lexical index. Title aliases, direct redirects, term statistics and lazy text access must be implemented. No article-by-article crawling, bulk embeddings, per-record LLM calls or GPU job is part of this scope.

The frozen priority contract designates 1,250,000 full-text articles and 5,248,498 explicit leads. The original 2–3 million full-text target was reduced under the authorized budget-adaptation rule; it must not be claimed achieved. Validate the exact final installed file set against the provisional 22,000,000,000-byte text/index budget. Source archives and rejected experiments are staging storage, not installed assets.

Check complete source-row dispositions, canonical selection, source hashes and rights-marker exclusions; distinguish these exhaustive metadata checks from sampled source-content checks. Inspect actual math, units, attribution and corruption counterexamples. Unknown rights, missing facts, the pageview aggregation interval and alias/text snapshot differences must remain explicit.

The original 80 development probes and separate 16 frozen low-count tail probes measure source-title retrieval, misses, latency and host memory. No post-result recall threshold is defined. They are not a private holdout, factual-answer gold set, generated-answer evaluation or human acceptance. Missing frozen locators must not be silently corrected.

All processing is constrained to LLMRig, two compute workers/CPUs, at most two HTTP requests and Arrow output batches below 2 GiB. Linux process RSS is separate from batch size and physical-device memory. The pack is not an Android integration, distribution-rights clearance, total-app 50 GB budget result, physical Android/GrapheneOS result, rival comparison or useful-synthesis acceptance result. The Android reader schema must accurately describe the delivered bytes and required FTS5 adapter.
