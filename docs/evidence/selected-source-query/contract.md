# Coherent selected-source query contract

This is a versioned `inline-units-v1` extension of the provisional selected-source v3 format. A reader requires all three query_contract/query_units/query_content objects and matching FTS external-content identity; unknown or incomplete extensions are rejected. Existing v2 and v3 leaf-search databases retain their legacy route. No live output or old database is rewritten.

Visible canonical leaf strings remain in `texts` once. Query units store article/revision, enclosing element, first/last leaf references, kind and projected-text SHA256. The SQL view concatenates referenced leaves in original node order; no ancestor/title/body projection strings are persisted in query_units. FTS4 stores normal term postings, not another source-body table. A metadata-title unit resolves its title from article metadata and is explicitly not sentence support.

A unit is a contiguous visible run within one block owner. Block starts, including empty blocks, omitted unsafe content, line breaks and media boundaries end runs. Inline formatting and entities do not break them. Paragraph AND and phrase semantics therefore survive bold/emphasis boundaries without combining separate blocks. There is no arbitrary 32K phrase split: a run is capped by the existing 16MB original bound. SQLite may materialize that bounded query projection; the host reader retrieves only a 240-character snippet and streams leaf hashes in bounded rows. This is not a measured million-article or Android memory guarantee. Two-second query deadlines and cancellation apply to SQLite progress and projection verification.

A returned hit carries unit/page/revision/node/kind, source and projection hashes, title, attribution URL and exact license metadata. Source opening requires an externally pinned immutable <=64MiB shard, full original/HTML capsule identity, exact metadata and structural context verification. Body hits reopen enclosing table/math/quotation context; title hits open article metadata and bounded original HTML windows, never inferred factual support. No external resources or executable HTML are loaded. The existing v1 export adapter retains URL/license/original bytes but does not transplant this new query index into Android.

Full original HTML/JSON and typed nodes remain inspection-only. Wikimedia's URL/stable-copy/author-list attribution alternatives do not require complete contributor history; actual imported attribution, modifications, licenses, nontext and quotation rights still need applicable review. No query hit becomes a generated answer or independently eligible context.

The tests comprise the independently frozen four authored originals, seven genuine originals, and seven supplemental authored controls for blocks, direct body/preformatted text, fragmented words, unsafe gaps and a long paragraph. Supplemental controls are development tests, not unseen cases or factual corpus breadth. A mistaken global absence expectation for `sunrise` was corrected to its authored page scope after a genuine Salar de Uyuni match; both failed runs and that genuine output are retained. The empty-block regression was reproduced before its fix.
