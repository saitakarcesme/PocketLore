# Task330 development protocol

Use existing PackLibrary transactions and active engine. A personal archive retains original bytes, exact extracted UTF-8 text and metadata with SHA256/UTF-16 passage spans. It is explicitly private provenance, not public redistribution permission. TXT/MD retain exact decoded text; CSV parses quoted/multiline records, escaped quotes and equal row widths; JSON uses strict bounded syntax and scalar JSON-pointer locations. PDF uses local Android35+ PdfRenderer text blocks with page/block provenance, never OCR. No new dependency or network permission.

Freeze tests before implementation: UTF-8 emoji TXT, Markdown, CSV quoted comma/escaped quote/multiline and malformed quote/row-width, JSON nested values/escaped strings and malformed/deep input, real text PDF plus empty/image-only/encrypted PDF, pre/during-copy cancellation, cancelled export, original/extracted hash corruption, exact UTF-16 citation spans, import/select/disable/restart/remove/export/reimport, unchanged saved model sentinel, actual reader/search controls and measured disk/heap/PSS. Fixtures are constructed parser tests, not factual corpus or quality claims. Existing303 capacity results do not validate this candidate.

Keep all prior test records. No inference required; shared search and source inspection establish retrieval only. Native PDF parsing calls cannot necessarily be interrupted mid-call; cancellation is checked before/after page/block operations. Full process resource isolation is not claimed. Collection export shares private original bytes, source location and ownership metadata only on explicit user export.
