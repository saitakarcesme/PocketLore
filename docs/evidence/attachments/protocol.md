# Task340 public development protocol

Use Tesseract English tessdata_fast and whisper.cpp tiny.en, pinned local CPU engines with two native threads. Optional model installation is explicit and hash-checked; no SpeechRecognizer, cloud fallback, OCR scene reasoning or automatic downloads. Existing typed input remains available. Return editable recognized input only after review; do not turn transcription into source evidence or a generated answer. Preserve original attachment hash/location and engine identity in the preview receipt. Do not modify Saved/history/bookmark/reader/export ownership.

Before validation freeze generated public OCR fixtures: rendered English sign, tilted/photograph-like sign, blank image, invalid image and oversized bounds. Speech uses the pinned upstream JFK sample (historical recording, exact fixture bytes/provenance retained), silence, deterministic white noise, malformed WAV, absent model, denied microphone permission and cancellation. These are public development checks, not private holdout, multilingual validation or microphone acoustic quality proof. One serial recognition job, maximum4MiB image input/4million decoded pixels/30second deadline and15second 16kHz mono PCM speech. Greedy English decoding,64 output tokens, no temperature retries; no-speech probability threshold0.6, silence energy threshold0.008. Preserve raw actual outputs including errors; do not manufacture expected transcriptions.

Build ARM64 and x86_64 JNI with16KB LOAD alignment and isolated native symbols; measure APK/optional model/cache/temp bytes and actual emulator PSS/latency. Test changed/missing assets, cancellation and retry, Activity UI/permission/absent paths, and absence of INTERNET/GMS.
