`ReviewedAnswerVerifier` adds an Android-compatible implementation of the existing whole-answer verifier interface. It binds the exact question, system prompt, complete draft and ordered source ID/title/text/URL/date/license/collection/offline-license bytes with length-prefixed SHA256 input. Review regions cover every non-whitespace output character, reject unsupported regions and preserve exact UTF16 source spans. Visible source labels must agree with inspected source spans; mutated source/draft/question bytes invalidate the review. Cancellation is checked before and after the external authority and during region validation. Malformed Unicode is rejected rather than normalized into an ambiguous identity. Regions, obligations and source lists are defensively copied and bounded.

This contract is not an automatic semantic validator. An external independently qualified review authority must inspect factual support, qualifiers, relevance, nonfactual-region classification and completeness. The program cannot determine those truths from the hash or offset structure. The ordinary app still has no such authority; NativePanel remains bound to UNAVAILABLE, and neither model nor test authority is installed as its reviewer.
