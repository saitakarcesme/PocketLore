# Structured source v1 inspection contract

Separate from compact-article-v1/FTS5 and legacy BroadPack/FTS4-porter. Schema version523 uses FTS4 unicode61 with external content nodes; only the exact frozen schema is accepted. Android execution is not yet measured.

An immutable `.plsource` has exactly manifest.json, index.sqlite and pinned complete CC-BY-SA3.0/4.0 legal texts. Manifest is at most2MiB, archive and installed index each at most64MiB. Content hash addresses each edition; the manifest is the last published catalog member. App-owned staging reservation covers three64MiB components plus ResourceStorage overhead; per-edition limits do not waive the global50GB meter. Exceptions/cancellation remove only files created by this import. Process death may retain orphan staged components for explicit recovery, never silently replace previous files.

`articles` retains page/title/exact metadata, original JSON SHA256, HTML SHA256 and lengths. `originals` carries exact original JSON in ordered <=32768-byte chunks, with independent chunk hashes. `html_chunks` carries <=8192UTF16 windows (no split surrogate), hashes and half-open offsets. These are actual offline bytes, not host references. They duplicate source data deliberately in this unoptimized engineering version; cost is reported rather than declared scale-fit.

`nodes` carries ordered typed structure, parent identity, exact original HTML half-open UTF16 ranges, inert attributes, and <=4096UTF16 leaf text. Literal data is exact. Character references map to exact original entity lexemes. Comments/doctype and executable/unsupported display material remain in the original, not research evidence. Complete source structure is re-tokenized on Android import and compared node-for-node, including attributes/parent/ranges/kinds. Unsupported grammar fails closed; no silent HTML repair. Syntactically valid math retains its exact markup tree; no numeric interpretation is authorized. Every source remains inspection-only, including prose, tables, quotations and references.

Reference href/id/backlink/data-mw attributes are exact source material; they are not locally verified external bibliography facts or license clearance. Table parent/row/header/caption containment is preserved. A search hit opens a bounded context window with exact highlighted leaf, ancestor context, row headers/captions and a corresponding original HTML window. All HTML displays as inert native text; no WebView or network resource resolution. Export is a labeled inspection window with original/edition hashes, metadata and offsets, using existing cancellable notebook SAF writing. It is not whole-article export or saved generated reasoning.

Reader uses20article/search results,40nodes or one8192UTF16 HTML window,2MiB SQLite cache and no mmap; import is bounded to one16MB original/4MB HTML/100000-node article at a time, depth64. These configured bounds are not measured Android peaks. The four original fixtures give no genuine MathML/quotation/nonBMP/long-article coverage; constructed fixtures are algorithm tests only.

The independent selected/latest index is separate and never changes rawstage or compact producer. It reads committed256-row metadata batches, closes each source handle before output writes, binds original metadata, retains conflicts/latest and joins page ID to the existing published importance input. No title/query selection. Oversized/missing sequence must stop rather than silently lose disposition. Current selector is engineering-only and not measured for production cgroup/disk/deadline enforcement; no launch is authorized. Final whole-source replay, complete raw identity, every disposition, genuine1.25M eligible floor, rights and Android full-profile budgets remain mandatory.
