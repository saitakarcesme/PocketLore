## Implemented behavior

The producer checks each bounded compressed original against its exact byte count and SHA256, and binds sequence, NDJSON member and uncompressed member offset. It preserves the original per-record 3.0 or 4.0 license identifier and exact URI, source dates, page/revision/title, original metadata and article-body metadata siblings, contributor credit and revision/history links. A linked history is not a complete offline contributor archive. Mixed or unknown license lists and wrong URIs are excluded; visible additional-rights notices, unknown structures, math/table/quotation elements and unsupported transformations retain explicit review dispositions. These signals never confer independent rights clearance.

Every consumed original has a disk-backed disposition. Greatest observed numeric revision wins, with deterministic ties. Different bytes for any previously seen same page/revision quarantine that page, including late older revisions; a newer invalid record never revives an older candidate. Raw-stage identity/digest conflicts fail the entire invocation. Oversized originals retain member/range/digest dispositions without guessing their unknown page or independently verifying omitted raw bytes; those remain promotion blockers. All originals and failed output directories stay retained.

The final product-format prototype stores one compressed complete visible article projection and metadata capsule. Delta-varint mappings preserve half-open original HTML and rendered UTF16 spans. Passage rows contain offsets and hashes only. An FTS5 external-content view indexes article terms with `detail=none,columnsize=0`, avoiding copied body text and positional postings. A bounded `capsule_text` decoder allows whole index-versus-content integrity checking. Search supports at most 12 query tokens and 20 article candidates, with cancellation before SQL and during passage scoring. A missing or changed index, source packet, license text, capsule or offset fails validation.

**Offline inspection contract:** the product capsule contains complete projected text, source metadata, original HTML SHA256 and source ranges. Exact original JSON/HTML remains in the retained host stage. The product does not contain original HTML bytes or claim byte-identical original JSON reconstruction. Literal tokens/entities reconstruct against retained originals; synthetic paragraph separators are explicitly nonfactual. Math/table/other uncertain structures remain inspectable in the originals and deny research candidacy. Active/media content is omitted from the projection with dispositions, never silently approved. Full details and Android decoder/import requirements are in `tools/packs/complete-source/FORMAT.md`.

## Discriminating failures and controls

Both first FTS4 attempts are preserved: contentless indexing could not supply original columns to SQLite 3.53.4 integrity checking; the first external-content view then omitted the required `rowid` alias. A one-row posting corruption test distinguishes that defect. FTS5 now performs explicit full content integrity before freezing. The initial fixture directory on `/tmp` failed the 100 GiB reserve; fixtures were moved to the ignored project filesystem without lowering the reserve. A transaction test caught VACUUM inside an open integrity-check transaction; that ordering was repaired. The two early unit failures were visible tool output but lacked standalone raw log files; the evidence inventory explicitly records that limitation rather than manufacturing logs.

Independent source review found late older-revision conflicts and stage metadata failures retaining stale candidates. The fixes have actual producer transaction regressions. Tests also cover unsafe newest revision, duplicate/late revisions, cancellation/deadline retention, retry without overwrite, oversized dispositions, wrong license URI, entity/astral UTF16 reconstruction, math/unknown content, changed postings, corrupt/missing index, changed/missing original packets and full license bytes. Constructed records are labeled algorithm fixtures and excluded from factual counts. All original failed producer receipts and logs remain available.
