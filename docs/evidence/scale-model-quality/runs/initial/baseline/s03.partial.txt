This is known as a binary search tree (BST). The left subtree of a node contains all the keys that are less than the node's key, and the right subtree contains all the keys that are greater than the node's key. The root node contains the key of the node itself. The tree is balanced, meaning that the height of the tree is logarithmic in the number of nodes. This ensures that the tree remains balanced and efficient in terms of search operations.
