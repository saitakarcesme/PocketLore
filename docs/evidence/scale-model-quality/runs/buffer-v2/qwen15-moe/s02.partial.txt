O1: Binary search tree

Insertion order can significantly affect the performance of a binary search tree. The order of insertion determines the height of the tree, which in turn affects the time complexity of operations. For example, if the nodes are inserted in a balanced manner, the tree will have a height of log n, resulting in linear time complexity for operations. However, if the insertion is done in an unbalanced manner, the tree can degenerate, leading to a height of n, which requires linear time for operations.

However, in the worst case, the tree can degenerate to the same time as a singly linked list, which requires [TeX: {\displaystyle O(n)}] time. To address the boundless increase of the tree height with arbitrary insertions and deletions, self-balancing variants of BSTs are introduced to bound the worst lookup complexity to that of the binary logarithm.
