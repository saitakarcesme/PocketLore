O1: Binary search narrows the possible position of a target by repeatedly dividing the search space in half. It compares the target value to the middle element of the array, eliminating the half in which the target cannot lie. If the search ends with the remaining half being empty, the target is not in the array.

O2: Binary search is faster than linear search except for small arrays. The array must be sorted first to apply binary search, which requires the same time as linear search.

O3: Binary search tree is a rooted binary tree data structure with the key of each internal node being greater than the ones in its left subtree and less than the ones in its right subtree. The time complexity of operations on the binary search tree is linear with respect to the height of the tree.

O4: Binary search tree is dependent on the order of insertion of the nodes into the tree, as arbitrary insertions may lead to degeneracy. Several variations of the binary search tree can be built with guaranteed worst-case performance.
