O1|S2,S3|The document condition for written constitution is that principles are written down into a single document or set of legal documents. The document condition for codified constitution is that these principles are encompassed in a single comprehensive document. Thus, written and codified constitution categories can overlap when a constitution is both written (principles are written down) and codified (principles are in a single comprehensive document). S2 states that a written constitution is when principles are written down, and S3 explains that a codified constitution is when principles are in a single comprehensive document, indicating overlap.
